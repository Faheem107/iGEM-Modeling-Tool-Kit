# UI Skills Reference

A concise list of the front-end / UI skills and libraries used to build a
web app I worked on. Shared so another agent has context on what I can do on
the UI side. Only the portfolio-relevant, transferable web skills are listed
here (domain-specific and scientific tooling has been intentionally left out).

> **No generic AI synthesis.** None of the UI in this project was generated by
> a generic AI website/page builder or a "make me a site" tool. Every component,
> layout, animation, and style was written and assembled by hand in code.

## Framework & language
- **Next.js 15** (App Router) with **React 19**
- **TypeScript** throughout

## Styling & design system
- **Tailwind CSS v4** (utility-first styling, PostCSS pipeline)
- **class-variance-authority**, **clsx**, **tailwind-merge** for composable
  variant-driven component styling
- **next-themes** for light/dark theming
- **Geist** font, **Lucide** icon set
- Custom shared primitives and a consistent radius/spacing scale

## Component library (accessible, headless)
- **Radix UI** primitives: dialog, popover, tabs, accordion, dropdown/menubar,
  tooltip, select, slider, switch, toast, scroll-area, and more
- Supporting UI: **cmdk** (command menu), **vaul** (drawers),
  **sonner** (toasts), **embla-carousel**, **input-otp**,
  **react-resizable-panels**, **react-day-picker**

## Animation & motion
- **GSAP** + **ScrollTrigger** for scroll-driven and pinned scene animation
- **Lenis** for smooth scrolling
- **anime.js v4**
- **Motion** (Framer Motion successor) and **@react-spring/web**
- **@paper-design/shaders-react** for shader-based visual backdrops

## Forms & validation
- **react-hook-form** with **zod** schemas via **@hookform/resolvers**

## Data & viz
- **Recharts** for charts and data visualization

## Tooling
- PostCSS, Autoprefixer
- `tsc --noEmit` for type-checking

## What this demonstrates
- Building polished, responsive, accessible interfaces from scratch
- Advanced scroll and motion choreography (GSAP + Lenis + ScrollTrigger)
- A hand-built design system on Tailwind + Radix
- Type-safe forms and state
- Clean componentization in a modern Next.js/React stack
